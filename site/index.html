Install the `rules` CLI on this machine.

2. ~/.config/git-policy/install.sh

Show me the output of steps 2 and 3 and tell me what changed on this machine. If `rules` is not found, run ~/.local/bin/rules.

If the folder in step 1 already exists, or the installer says it left any git hooks alone, ask me before changing anything.

Do not edit ~/AGENTS.md directly. If you want to change the rules, run `rules propose` and tell me a proposal is waiting for my review.
  • Clones Agent Rules into ~/.config/git-policy
  • Adds the rules command at ~/.local/bin/rules
  • Creates a starter ~/AGENTS.md, or keeps the one you have
  • Links 8 tool configs to that file and adds one import line to ~/.claude/CLAUDE.md
  • Leaves config files you wrote untouched. A config that is already a link to another file is pointed at yours
  • Sets git’s global hooks path to ~/.git-hooks. A path or hook you already have is left alone, and the installer says so
  • Uploads nothing from your machine

Agents propose. You approve.

rules edit, rules review and rules approve refuse to run when they detect an agent. The agent writes a proposal instead, and your rules stay as they are until you accept it

  1. Write the change you want as a proposal:

Bad commits stop at your machine

Three global git hooks run on every commit and push, whichever agent typed the command

What the agent triesWhat git answersHook
Commit on mainrefusing to commit directly to protected branch 'main'pre-commit

Write a 90-character subjectcommit subject is 90 chars, limit is 72commit-msg
Push straight to mainrefusing to push directly to protected branch 'main'pre-push
Force-push mainrefusing to force-push protected branch 'main'pre-push

Protected branches are main, master, develop and release/*. A new repository’s first commit is allowed

What it can’t stop

Everything here runs as your user, so treat it as a strong guard and not a wall

An agent writing to the file directly
A shell command can still change ~/AGENTS.md. rules check compares the file with your last approval and reports “changed outside the CLI”
An agent skipping the hooks
--no-verify skips the commit and push checks, and several block messages print a one-off override
The fix for both
Add branch rules on GitHub, where nothing on your machine can skip them. The included script previews them with ./scripts/apply-github-ruleset.sh --dry-run --all. Private repositories need a paid GitHub plan
