Free and MIT licensed. Needs macOS or Linux, bash and git

Install the `rules` CLI on this machine.

1. git clone https://github.com/koryei/rules ~/.config/git-policy
2. ~/.config/git-policy/install.sh
3. rules

Show me the output of steps 2 and 3 and tell me what changed on this machine. If `rules` is not found, run ~/.local/bin/rules.

If the folder in step 1 already exists, or the installer says it left any git hooks alone, ask me before changing anything.

Do not edit ~/AGENTS.md directly. If you want to change the rules, run `rules propose` and tell me a proposal is waiting for my review.
  • Clones Agent Rules into ~/.config/git-policy
  • Adds the rules command at ~/.local/bin/rules
  • Creates a starter ~/AGENTS.md, or keeps the one you have
  • Links 8 tool configs to that file and adds one import line to ~/.claude/CLAUDE.md
  • Leaves config files you wrote untouched. A config that is already a link to another file is pointed at yours
  • Sets git’s global hooks path to ~/.git-hooks. A path or hook you already have is left alone, and the installer says so
  • Uploads nothing from your machine
